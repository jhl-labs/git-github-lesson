초보 개발자를 위한 하루 과정

Git이 처음이어도, 오늘 퇴근 전에 GitHub로 서비스를 배포합니다

브라우저 안에서 진짜 Git을 직접 쳐 보며 개념을 잡고, Claude Code와 함께 엑셀 → GitHub Actions → GitHub Pages 대시보드를 만들어 봅니다. 설치 없이 바로 시작하세요.

🧪 Git 실습실 바로 가기 처음부터 차근차근 →

이 과정에서 배우는 4가지

01Git내 컴퓨터에서 코드의 변경 이력을 기록하는 도구. 터미널에서 직접 실습합니다.
02GitHubGit 저장소를 인터넷에 올려 공유·협업하는 서비스. 이슈와 PR을 씁니다.
03GitHub Actions"이 일이 생기면 저 일을 해라" — GitHub 안의 자동화 로봇입니다.
04GitHub Pages저장소의 파일을 그대로 웹사이트로 공개해 주는 무료 호스팅입니다.

오늘 완성할 실습 서비스

엑셀 파일을 GitHub 이슈에 올리기만 하면, 몇 분 뒤 웹 대시보드가 저절로 갱신되는 서비스입니다.

나엑셀 업로드GitHub 이슈에 .xlsx 첨부
ActionsWindows runner이슈 등록을 감지해 자동 실행
Actionsxlwings 변환엑셀 → data.json
Gitdocs 브랜치 커밋봇이 대신 commit & push
Pages대시보드비밀번호 로그인 후 차트·표

완성본이 궁금하다면 완성 예시 대시보드를 열어 보세요. (비밀번호: gitpages2026)
