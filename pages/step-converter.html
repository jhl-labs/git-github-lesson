Step 2 · 엑셀 → JSON 변환기

웹 페이지는 엑셀 파일을 직접 읽기 어렵습니다. 그래서 엑셀을 웹이 좋아하는 형식인 JSON으로 바꿔 주는 파이썬 스크립트를 만듭니다.

잠깐 이론: 왜 JSON인가요?

JSON은 웹에서 데이터를 주고받는 사실상의 표준 형식이에요. 엑셀의 한 행은 JSON의 객체 하나가 됩니다.

엑셀 (사람이 보기 좋음)

월지역매출액
2026-01서울12,000,000
2026-01부산8,400,000

JSON (프로그램이 읽기 좋음)

{ "rows": [
  { "월": "2026-01-01", "지역": "서울", "매출액": 12000000 },
  { "월": "2026-01-01", "지역": "부산", "매출액": 8400000 }
] }

xlwings vs openpyxl

xlwingsopenpyxl
동작 방식실제 Excel 앱을 띄워 조종.xlsx 파일 내부(XML)를 직접 해석
필요 환경Windows/macOS + Excel 설치파이썬만 있으면 어디서나 (Linux 포함)
수식 셀Excel이 계산한 최신 결과마지막 저장 시 캐시된 값만
속도느림 (Excel 실행 수 초)빠름

실습 목표상 xlwings를 기본으로 쓰되, Excel이 없는 환경에서도 실습이 멈추지 않도록 실패하면 openpyxl로 자동 대체하게 만듭니다. (GitHub이 제공하는 Windows runner에는 Excel이 설치되어 있지 않을 수 있어요. 어떤 엔진으로 변환됐는지는 대시보드와 로그에 표시합니다.)

2-1. 변환기 만들기

먼저 작업용 브랜치를 만들고 Claude Code에 아래 프롬프트를 붙여넣으세요.

git switch -c feature/converter

2-2. 직접 돌려 보기

샘플 엑셀을 내려받아 변환해 보세요. (Claude에게 "샘플 엑셀로 실행해 보고 결과 JSON 앞부분을 보여줘"라고 해도 됩니다.)

📥 sales-2026-h1.xlsx 내려받기

pip install -r scripts/requirements.txt pytest
python -m pytest -q
python scripts/excel_to_json.py sales-2026-h1.xlsx --out build/data.json
# Excel이 없는 PC라면: ::warning::xlwings 실패 ... → openpyxl 로 대체되는 것이 정상
⚠️ build/ 폴더는 커밋하지 않아요 변환 결과는 Actions가 매번 새로 만듭니다. .gitignore에 build/, __pycache__/를 추가하세요. (실습실 미션 2에서 배운 그 .gitignore입니다!)

2-3. 커밋하고 main에 합치기

git add .
git commit -m "엑셀 → JSON 변환기와 테스트 추가"
git switch main
git merge feature/converter
git push

회사 엑셀에 =SUM(B2:B10) 같은 수식이 많고, 누군가 값을 바꾼 뒤 Excel이 아닌 다른 프로그램으로 저장했습니다. 어느 엔진이 더 정확한 값을 읽을까요?

정답! openpyxl은 수식을 계산하지 못하고 "마지막으로 저장된 계산값"만 읽어요. 이게 xlwings를 쓰는 이유이자, Windows + Excel 환경이 필요한 이유입니다.
