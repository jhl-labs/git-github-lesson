Step 2 · 엑셀 → JSON 변환기

웹 페이지는 엑셀 파일을 직접 읽기 어렵습니다. 그래서 엑셀을 웹이 좋아하는 형식인 JSON으로 바꿔 주는 파이썬 스크립트를 만듭니다.

📚 시작 전 이론: 엑셀 파일의 속, JSON, 파이썬 도구

변환기를 AI에게 맡기더라도, 엑셀이 어떻게 저장되고 JSON이 무엇을 표현할 수 있는지 알아야 결과가 맞는지 판단할 수 있어요. 특히 수식과 날짜는 초보자가 가장 많이 틀리는 부분입니다.

.xlsx
엑셀 파일 형식. 정체는 여러 개의 XML 파일을 ZIP으로 압축한 묶음이에요.
JSON
웹에서 데이터를 주고받는 텍스트 형식. 객체 {}와 배열 []로 구조를 표현합니다.
xlwings
설치된 Microsoft Excel 프로그램을 파이썬에서 원격 조종하는 라이브러리 (Windows에서는 COM이라는 통로 사용).
openpyxl
Excel 없이 .xlsx 안의 XML을 직접 해석하는 순수 파이썬 라이브러리. Linux에서도 동작해요.
가상환경 (venv)
프로젝트마다 따로 쓰는 파이썬 라이브러리 설치 공간. 다른 프로젝트와 버전이 섞이지 않게 해요.
pytest
파이썬 테스트 도구. test_*.py 파일의 test_로 시작하는 함수를 찾아 실행하고 assert가 맞는지 확인합니다.

.xlsx는 사실 ZIP 파일이에요

확장자를 .zip으로 바꿔 열어 보면 이런 구조가 보입니다. 그래서 첨부 파일 검사 스크립트는 "파일이 ZIP 서명인 PK로 시작하는가"를 확인해요.

sales.xlsx (= ZIP)
├── [Content_Types].xml
└── xl/
    ├── workbook.xml          ← 시트 목록
    ├── worksheets/sheet1.xml ← 셀 값과 수식
    ├── sharedStrings.xml     ← 글자 셀의 문자열 모음
    └── styles.xml            ← 서식 (날짜 표시 형식도 여기!)

엑셀 한 행 = JSON 객체 하나

엑셀 (사람이 보기 좋음)

월지역매출액
2026-01서울12,000,000
2026-01부산8,400,000

JSON (프로그램이 읽기 좋음)

{ "rows": [
  { "월": "2026-01-01",
    "지역": "서울",
    "매출액": 12000000 },
  { "월": "2026-01-01",
    "지역": "부산",
    "매출액": 8400000 }
] }

JSON의 값 종류는 문자열·숫자·true/false·null·객체·배열 여섯 가지뿐이에요. 날짜 타입이 없어서 "2026-01-01" 같은 문자열로 약속해 저장합니다. 또 12,000,000의 쉼표는 엑셀의 "보여주기 서식"일 뿐이라 JSON에는 숫자 12000000으로 들어가야 해요. 한글은 UTF-8로 저장하면 그대로 읽힙니다.

xlwings vs openpyxl

xlwingsopenpyxl
동작 방식실제 Excel 앱을 띄워 조종.xlsx 파일 내부(XML)를 직접 해석
필요 환경Windows/macOS + Excel 설치파이썬만 있으면 어디서나 (Linux 포함)
수식 셀Excel이 계산한 최신 결과마지막 저장 시 캐시된 값만
속도느림 (Excel 실행 수 초)빠름

실습 목표상 xlwings를 기본으로 쓰되, Excel이 없는 환경에서도 실습이 멈추지 않도록 실패하면 openpyxl로 자동 대체하게 만듭니다. GitHub이 제공하는 Windows runner는 진짜 Windows 서버지만 Microsoft Office(Excel)는 설치되어 있지 않아요. 그래서 그 위에서는 대체가 일어나는 것이 정상이고, 어떤 엔진으로 변환됐는지는 대시보드와 로그에 표시합니다.

수식과 "캐시된 값"

셀에 =SUM(B2:B10)이 있으면 파일에는 수식과 마지막으로 계산된 결과가 함께 저장됩니다. openpyxl은 계산을 못 하므로 data_only=True 옵션으로 이 "저장된 결과"를 읽어요. Excel이 아닌 프로그램이 수식을 계산하지 않고 저장했다면 결과 칸이 비어 None이 나올 수 있습니다. xlwings는 Excel이 직접 다시 계산하니 이런 문제가 없어요.

날짜의 함정

엑셀은 날짜를 내부적으로 숫자(일련번호)로 저장하고, 서식으로 "2026-01-01"처럼 보여줄 뿐입니다. (예: 1900-01-01이 1부터 시작하는 날수) 라이브러리가 서식을 보고 날짜로 바꿔 주지 않으면 JSON에 46023 같은 엉뚱한 숫자가 들어가요. 그래서 프롬프트에 "날짜는 YYYY-MM-DD 문자열"이라고 명시합니다.

파이썬 작업 환경: venv · requirements · pytest

python -m venv .venv                 # 프로젝트 전용 파이썬 공간 만들기
source .venv/bin/activate            # macOS/Linux  (Windows: .venv\Scripts\activate)
pip install -r scripts/requirements.txt   # 적힌 버전 그대로 설치
python -m pytest -q                  # tests/ 의 테스트 실행
  • requirements.txt에 openpyxl==3.1.5처럼 버전을 고정하면, 내 PC와 runner가 똑같은 라이브러리로 실행돼 "내 PC에선 됐는데" 문제가 줄어요.
  • 테스트는 Excel 없이도 돌아야 하므로 openpyxl로 임시 엑셀을 만들어 검증하고, xlwings 실패 상황은 monkeypatch(테스트 중에만 함수를 바꿔치기)로 흉내 냅니다.
  • .venv/는 커밋하지 않아요. 누구나 requirements.txt로 다시 만들 수 있으니까요.
