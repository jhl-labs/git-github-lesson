Git 명령 치트시트

상황명령
처음 설정git config --global user.name "이름"
git config --global user.email "메일"
새 저장소 / 복제git init · git clone <주소>
상태 확인git status · git status -s
무엇이 바뀌었나git diff(작업↔스테이징) · git diff --staged(스테이징↔커밋)
스테이징git add 파일 · git add .
커밋git commit -m "메시지" · git commit -am "메시지"(추적 중인 파일 한 번에)
기록 보기git log --oneline --all · git show 커밋
브랜치git branch · git switch -c 새브랜치 · git switch main · git branch -d 브랜치
병합git merge 브랜치 · 충돌 시 파일 수정 → git add → git commit · 취소 git merge --abort
원격git remote -v · git push -u origin main · git fetch · git pull
브랜치·과거 커밋 이동 (옛 방식)git checkout 브랜치 · git checkout -b 새브랜치 · git checkout HEAD~1(과거 구경, detached HEAD)
파일 수정 취소git restore 파일 (= git checkout -- 파일)
스테이징 취소git restore --staged 파일
마지막 커밋 취소 (push 전)git reset --soft HEAD~1(변경 유지) · git reset --hard HEAD~1(변경 삭제 ⚠️)
push한 커밋 되돌리기git revert 커밋 (되돌리는 새 커밋을 만듦 — 이력을 지우지 않아 안전)

GitHub CLI(gh) 치트시트

gh repo create 이름 --public --clone      # 저장소 생성 + clone
gh issue list / gh issue view 3            # 이슈
gh pr create --fill                        # 현재 브랜치로 PR 생성
gh pr diff 1 / gh pr checks 1              # PR 변경 내용 / 검사 상태
gh pr merge 1 --squash --delete-branch     # PR 병합
gh run list / gh run watch                 # Actions 실행 목록 / 실시간 보기
gh run view <id> --log-failed              # 실패한 단계 로그만
gh secret set 이름                          # Actions Secret 등록

용어집

용어한 줄 설명
Repository (저장소)프로젝트 파일 + 전체 변경 이력. .git 폴더가 본체
Commit특정 시점의 스냅샷. 고유 해시 ID와 부모 커밋을 가짐
Staging Area (Index)다음 커밋에 넣을 변경을 모아두는 곳
Branch커밋을 가리키는 이동식 이름표
HEAD지금 내가 보고 있는 브랜치(커밋)를 가리키는 표시
Merge / Conflict두 브랜치 합치기 / 같은 줄을 다르게 고쳐 자동으로 못 합치는 상황
Remote / origin원격 저장소 / 그 기본 별명
Pull Request내 브랜치를 합쳐 달라는 GitHub의 요청·리뷰 공간
Workflow / Job / StepActions 자동화 파일 / runner 한 대의 작업 묶음 / 개별 명령
Runner워크플로우를 실제로 실행하는 머신. GitHub-hosted는 job마다 새로 만들어지는 클라우드 VM, self-hosted는 내가 준비한 서버
Secret워크플로우에서 쓰는 암호화된 비밀 값
GitHub Pages저장소 파일을 웹사이트로 공개하는 정적 호스팅

좋은 프롬프트 체크리스트

  • 목표를 한 문장으로 먼저 말했다 (무엇을, 왜)
  • 입력과 출력의 형식을 예시로 보여줬다 (파일 경로, JSON 모양)
  • 제약을 적었다 (언어, 라이브러리, 보안 규칙, 하지 말 것)
  • 확인 방법을 요청했다 (테스트 실행, 실행 결과 보여주기)
  • 한 번에 하나의 Step만 시키고, 끝나면 커밋했다
