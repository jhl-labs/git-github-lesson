Step 1 · GitHub 저장소와 Claude Code

GitHub의 핵심 개념을 훑어보고, 실습용 저장소를 만든 뒤 Claude Code를 연결합니다.

GitHub 한눈에 보기

GitHub는 Git 저장소를 인터넷에 올려두는 곳이자, 그 위에서 협업하기 위한 도구 모음입니다. 오늘 쓸 기능은 다섯 가지예요.

📁

Repository

프로젝트 하나 = 저장소 하나. 코드와 전체 커밋 기록이 들어 있어요.

🐛

Issues

할 일·버그·요청을 적는 게시판. 오늘은 엑셀 업로드 창구로 씁니다.

🔀

Pull Request

"내 브랜치를 main에 합쳐 주세요" 요청. 여기서 코드 리뷰를 해요.

⚙️

Actions

이벤트가 생기면 자동으로 스크립트를 실행하는 로봇.

🌐

Pages

저장소 파일을 그대로 웹사이트로 공개.

Public과 Private

Public 저장소는 전 세계 누구나 코드를 볼 수 있고, Private은 초대한 사람만 볼 수 있어요. 무료 계정에서 GitHub Pages를 쓰려면 저장소가 Public이어야 합니다. 그래서 오늘 실습 저장소는 Public으로 만들고, 민감한 실제 데이터는 절대 올리지 않습니다.

1-1. 저장소 만들기

원하는 작업 폴더에서 실행하세요. 저장소 생성 + 내 컴퓨터로 clone까지 한 번에 됩니다.

gh repo create excel-dashboard --public --clone --add-readme --description "엑셀 → GitHub Actions → Pages 대시보드 실습"
cd excel-dashboard
git log --oneline   # Initial commit 하나가 보이면 성공
  1. github.com 우측 상단 + → New repository
  2. 이름 excel-dashboard, Public, "Add a README file" 체크 → Create
  3. 초록색 Code 버튼에서 HTTPS 주소 복사 후 clone 
    git clone https://github.com/<내아이디>/excel-dashboard.git
cd excel-dashboard
🔗 Git 실습실과 연결해 보세요 방금 한 일은 실습실 미션 5의 git clone과 같아요. 원격(GitHub)에 저장소가 먼저 생기고, 그걸 내 컴퓨터로 복사했습니다. git remote -v를 쳐 보면 origin이 GitHub 주소로 이미 연결되어 있을 거예요.

1-2. Claude Code 시작하기

저장소 폴더 안에서 Claude Code를 실행합니다. Claude Code는 현재 폴더의 파일을 읽고, 명령을 실행하고, 파일을 고칠 수 있는 AI 코딩 도구예요.

claude
✦ 바이브 코딩 3원칙
  1. 목표와 제약을 구체적으로 — "대시보드 만들어줘"보다 "data/data.json을 읽어 KPI 카드·막대 차트·표를 보여주는 정적 페이지"가 훨씬 낫습니다.
  2. 작게 나눠서 — 한 번에 전부 시키지 말고 Step마다 하나씩. 각 Step이 끝나면 커밋해서 되돌아갈 지점을 만듭니다.
  3. 결과는 반드시 확인 — Claude가 보여주는 변경 내용(diff)을 읽고, 직접 실행해 보고, 이상하면 그대로 말해 주세요.

1-3. 첫 프롬프트: 프로젝트 설명서(CLAUDE.md) 만들기

CLAUDE.md는 Claude Code가 매번 읽는 "프로젝트 설명서"입니다. 이걸 먼저 만들어 두면 이후 프롬프트가 훨씬 짧아져요.

Claude가 만든 CLAUDE.md를 열어 읽어 본 뒤, 마음에 들면 커밋하고 push 합니다. 실습실에서 했던 그대로예요.

git status
git add CLAUDE.md
git commit -m "프로젝트 설명서 추가"
git push
💡 Claude Code에게 커밋을 맡겨도 돼요 "변경 사항 커밋하고 push 해줘"라고 말하면 Claude가 git add → git commit → git push를 대신 실행합니다. 단, 처음에는 직접 쳐 보면서 실습실에서 배운 개념과 연결해 보세요.
