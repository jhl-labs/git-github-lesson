준비물 체크

PART 1(Git 실습실)은 브라우저만 있으면 됩니다. PART 2(실전 프로젝트)를 위해 아래를 미리 준비해 두세요.

필수 체크리스트

  • GitHub 계정 — github.com/signup에서 가입하고 이메일 인증까지 마치기
  • Git 설치 — 터미널에서 git --version이 버전을 출력하면 OK
  • GitHub CLI(gh) 설치 & 로그인 — gh auth login 후 gh auth status로 확인
  • Claude Code 설치 & 로그인 — claude를 실행해 로그인 화면이 나오면 OK. 공식 설치 스크립트를 쓰면 Node.js가 필요 없어요. (무료 Claude 플랜은 Claude Code를 쓸 수 없어 Pro·Max·Team·Enterprise 또는 Console(API) 계정이 필요합니다)
  • (선택) VS Code — 코드를 눈으로 확인할 편집기
  • (선택) Python 3.12 — 변환 스크립트를 내 컴퓨터에서도 돌려보고 싶다면

운영체제별 설치 명령

PowerShell에서 실행하세요. (관리자 권한은 필요 없어요. 설치 중 권한 확인 창이 뜨면 허용하세요)

winget install --id Git.Git -e
winget install --id GitHub.cli -e
irm https://claude.ai/install.ps1 | iex
# 설치가 끝나면 새 터미널을 열어 확인
brew install git gh
curl -fsSL https://claude.ai/install.sh | bash
sudo apt update && sudo apt install -y git gh curl
curl -fsSL https://claude.ai/install.sh | bash

설치 확인

아래 명령이 모두 버전 번호를 출력하면 준비 완료입니다.

git --version
gh --version
claude --version

Git 첫 설정 (한 번만)

커밋에는 "누가 만들었는지"가 기록됩니다. GitHub 가입 이메일과 같게 설정하는 것을 권장해요.

git config --global user.name "홍길동"
git config --global user.email "hong@example.com"
git config --global init.defaultBranch main
✦ 바이브 코딩이란? 코드를 한 줄씩 직접 쓰는 대신, AI에게 "무엇을 만들고 싶은지"를 자연어로 설명하고 결과를 확인·수정하며 개발하는 방식입니다. 이 과정에서는 Claude Code를 씁니다. 중요한 건 AI가 만든 결과를 읽고, 실행해 보고, 검토하는 능력이에요. 그래서 Git 개념을 먼저 확실히 잡고 갑니다.
⚠️ 회사 PC를 쓰는 경우 사내 보안 정책으로 GitHub 접속이나 npm 설치가 막혀 있을 수 있습니다. 미리 담당자에게 확인하세요. PART 1의 Git 실습실은 인터넷 없이도(첫 로딩 후) 동작합니다.
