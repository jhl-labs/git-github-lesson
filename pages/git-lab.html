인터랙티브 Git 실습실

왼쪽 미션을 따라 터미널에 명령을 입력하세요. 명령 칩을 클릭하면 입력창에 채워집니다. 오른쪽(또는 아래) 시각화는 작업 디렉터리 · 스테이징 · 로컬 저장소 · GitHub를 실시간으로 보여줍니다.

처음부터 다시터미널 위의 초기화 버튼 (또는 새로고침)
🔬 이 터미널은 어떻게 동작하나요? C로 작성된 Git 라이브러리 libgit2를 WebAssembly로 컴파일한 wasm-git이 브라우저 메모리 속 가상 파일시스템에서 실제 커밋 객체를 만듭니다. "가상 GitHub"도 같은 메모리 안의 bare 저장소예요. 몇몇 명령(branch, switch, restore, pull 등)은 실제 git과 같은 결과가 나오도록 실습실이 보완합니다. 그래서 여기서 익힌 명령은 실제 터미널에서도 그대로 쓸 수 있습니다.
실제 Git과 다른 점 편집기(vim)가 없어 커밋 메시지는 반드시 -m "메시지"로 적어요. rebase, stash, --amend 같은 고급 명령은 지원하지 않습니다. 새로고침하면 모든 실습 내용이 사라집니다.
